Analysis policy
Data privacy
Heads up: AI analysis runs in the background. If AI blocking is enabled for a site, it can temporarily block a client on that site. An AI error leaves existing WAF protection active. Only trusted proxies may supply the original client IP, which is used consistently for protection, logs, and routing. Credentials are removed from selected headers and query fields, but shared request details may still contain sensitive data.
High availability
Synchronization uses a separate HTTPS address and credential. Configure this device’s WAF_HA_PEER_TOKEN locally; enter the peer node's dedicated HA token above. Shared protection settings are copied; each device keeps its own role, peer connection, users, and secrets. Configure automatic IP failover separately with keepalived/VRRP or your load balancer. Use the health check at /healthz and read role from /api/ha.
Notifications
Notifications always appear under the bell. A webhook also sends them to another service. A saved webhook address is hidden; leave this field blank to keep it, or use Clear stored webhook to remove it explicitly. Suggestions never auto-apply.

Package ready — review before installing
How trust works: The publisher’s verification key checks each package before it is prepared. Packages with an invalid signature, checksum, or file path are rejected.
